# Distributed Event Processing & Real-Time Analytics Platform

A distributed, event-driven platform for high-throughput event ingestion,
asynchronous processing, and real-time analytics.

## Architecture

Client
→ API Gateway
→ Ingestion Service
→ Kafka
→ Processing Service
→ PostgreSQL / Redis
→ Analytics API

## Technology Stack

- Java 25
- Spring Boot
- Apache Kafka
- Redis
- PostgreSQL
- Docker
- AWS
- Maven

## Services

- API Gateway
- Ingestion Service
- Processing Service
- Analytics Service
- Common
